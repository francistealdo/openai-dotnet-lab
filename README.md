# OpenAI .NET Lab

A full-stack sandbox project for experimenting with OpenAI APIs using .NET 10 and React.

## Current features

- Basic chat completions
- Chat completions with generation options
- Prompt templates
- Recipe generation
- Image generation
- React frontend for chat, recipes, and image generation
- OpenAPI documentation with Scalar
- CORS configuration for local frontend integration

## Tech stack

### Backend
- .NET 10
- ASP.NET Core Web API
- OpenAI .NET SDK
- Scalar / OpenAPI

### Frontend
- React
- TypeScript
- Vite
- Axios
- ESLint
